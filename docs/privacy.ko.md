# 개인정보와 데이터 처리

시행일: 2026년 11월 8일. 관리자: [stlahxm](https://github.com/stlahxm). [English](privacy.md)

## podium이 하는 일

podium은 Claude 호스트를 통해 동작하는 지침과 템플릿입니다. 관리자가 운영하는 별도 호스팅 백엔드·번들 MCP 서버·telemetry 수집기·데이터베이스는 없습니다.

절차를 사용하면 호스트에 관련 프로젝트 파일·세션 메타데이터를 읽거나, 작업 공간 파일을 만들고 고치거나, 해당 호스트가 제공하는 도구로 세션을 관리하도록 요청할 수 있습니다. 업무 파일에는 작업 설명·이름·결정·다음 행동·세션 식별자가 들어갈 수 있습니다. 사용자가 자료에 포함한 개인정보도 작업 공간에서 읽고 저장할 수 있습니다. 인증 정보나 다른 민감 정보를 업무 기록에 넣지 마세요.

이전 결정을 찾아 달라고 요청하면 `find`는 프로젝트 파일만으로 부족할 때 호스트의 세션 검색으로 이전·보관 대화의 관련 발췌를 읽을 수 있습니다. 세션 메타데이터뿐 아니라 대화 내용도 포함될 수 있습니다. 필요한 부분만 읽고 출처를 밝히며, 대화 내용을 업무 파일에 복사하기 전에는 승인을 받도록 안내합니다. 파일 저장 승인은 다른 곳으로의 전달 승인이 아닙니다.

## 처리·전송 위치

관리자는 podium 자체 서비스로 사용자의 프로젝트 파일을 받지 않습니다. 호스트 모델과 도구가 읽은 자료는 해당 제공자의 약관·개인정보 설정·보관 규칙에 따라 처리됩니다. 작업 공간은 사용자 컴퓨터나 호스팅·동기화된 위치에 있을 수 있습니다. podium은 모든 처리·저장이 기기 안에서만 이루어진다고 보장하지 않습니다.

플러그인에는 별도 커넥터나 자동 분석 전송 기능이 번들되지 않습니다. 외부 메시지·게시 등 외부 행동에는 승인이 필요하다고 지시합니다. 사용자가 호스트의 외부 도구 사용이나 파일 공유를 승인하면 대상 서비스가 자체 정책에 따라 데이터를 받을 수 있습니다. 승인 전에 대상과 자료를 확인하세요. 설치·업데이트는 GitHub에서 공개 소스를 내려받으며 사용자의 업무 파일을 관리자에게 올리지 않습니다.

관련 제공자 정책은 [Anthropic 개인정보 처리방침](https://www.anthropic.com/legal/privacy), [GitHub 일반 개인정보 처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)을 참고하세요. 사용자가 선택한 다른 호스트·커넥터·저장소·서비스에는 각각의 정책이 적용됩니다.

## 보관과 제어

podium은 작업 데이터를 받는 서비스를 운영하지 않으므로 관리자 서버의 보관 기간이 없습니다. 작업 공간에 만든 파일은 사용자가 수정·삭제할 때까지 남으며 자동 만료·삭제 작업은 없습니다. 세션 이력·캐시·동기화 파일·백업은 호스트와 저장 시스템이 관리하며 프로젝트 파일과 별도로 남을 수 있습니다.

사용자는 작업 공간 기록을 열람·수정·삭제하고 플러그인 사용을 중단하거나 제거할 수 있습니다. 플러그인을 제거해도 이전에 만든 기록은 삭제되지 않습니다. 호스트 보관 데이터나 백업은 해당 제공자의 제어 기능을 사용하세요.
