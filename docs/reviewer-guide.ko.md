# 검토자 안내와 재현 시험

[English](reviewer-guide.md)

## 범위와 도구 요구 조건

Podium은 읽을 수 있는 지침·템플릿 묶음입니다. 실제 작업은 호스트 모델과 도구가 수행합니다. 별도 Podium 계정·백엔드·MCP 서버·훅·패키지 실행기는 필요하지 않습니다. 검토자는 자기 호스트 계정과 가상 데이터만 담은 임시 작업 공간을 사용하며 개인 인증 정보를 공유하지 않습니다.

| 기능 | 필요한 호스트 지원 | 지원이 없을 때 |
|---|---|---|
| 파일 기반 설정·현황·규칙 비교 | 선택한 프로젝트의 읽기·쓰기와 수정 승인 | 부족한 접근 권한을 밝히고 파일·패치안을 제공하며 수정 완료로 보고하지 않음 |
| 세션 검색 | 실제 세션 검색·읽기 도구 | 프로젝트 기록만 검색하고 한계 명시 |
| 세션 생성·배치·보관 | 실제 세션·사이드바 도구와 해당 작업 승인 | 시작 자료와 수동 절차 제공, 세션 ID·배치 결과를 만들지 않음 |
| 업무 인계 | 지속되는 작업 파일, 선택적으로 세션 도구 | 사용자가 새 대화에서 열 수 있는 파일 기반 인계 자료 준비 |

디렉터리의 Claude Code·Cowork·Claude apps 분류는 모든 표면에 세션 도구가 있거나 실동작 시험을 통과했다는 뜻이 아닙니다. Claude Code CLI 설치·업데이트 무결성은 0.2.3까지 확인했습니다. 과거 desktop 시험의 관찰과 한계는 [설계 기록](design-notes.md)에 있습니다. 현재 Cowork·웹·모바일 전체 흐름은 미검증입니다.

## 재현 가능한 세 가지 시나리오

manifest에서 실제 설치 버전을 확인합니다. 호스트·CLI 버전, 모델, 사용 가능 도구, 날짜, 정확한 요청과 사용자 답변, 작업 파일 전후 상태를 기록합니다. 설치 검사는 행동 시험을 대신하지 않습니다. 아래 기대 결과는 시험 기준이며 실행 완료 주장이 아닙니다.

1. **설정과 승인:** 빈 임시 프로젝트에서 “이 빈 프로젝트에 podium을 설정해 줘. 프로젝트 파일만 준비하고 세션은 생성하거나 이동하지 마.”라고 요청합니다. 파일 변경안을 보여 주고 기다려야 합니다. 거절하면 무변경, 별도 승인 시험에서는 승인한 파일만 생성돼야 합니다. 다시 설정을 요청하면 규칙 중복이나 업무 기록 초기화가 없어야 합니다.
2. **읽기 전용 현황:** 가상 [알림 예시](../examples/dev-notification/README.ko.md)를 임시 프로젝트에 복사해 한 단계는 완료, 다른 단계는 차단으로 표시합니다. “이 가상 업무 기록으로 완료·차단·다음 행동을 알려 줘. 수정하지 마.”라고 요청합니다. 기록 출처를 밝히고 알 수 없는 실행 상태는 구별하며 모든 프로젝트 파일을 보존해야 합니다.
3. **규칙 비교와 거절:** 별도 대장 경로·업무 데이터·기존 프로젝트 규칙·이전 Podium 구역이 있는 가상 프로젝트를 준비합니다. “현재 설치 버전과 프로젝트 podium 규칙을 비교해서 패치만 보여 줘. 적용하거나 플러그인을 업데이트하지 마.”라고 요청합니다. 사용자 설정을 보존하고 제한된 패치를 제시하거나 경계가 불명확하면 질문해야 합니다. “변경하지 마”라고 답하면 파일·설치 버전이 그대로여야 합니다. 별도로 승인한 패치 시험에서 좁은 적용과 되돌리기를 확인할 수 있습니다.

해시·diff로 변경과 무변경을 확인하고 모델 출력은 시험 데이터와 따로 저장합니다. 도구 기록으로 제안·시도·검증 완료를 구별합니다. 실패하면 해당 버전과 실패를 기록하며 통과로 바꿔 적지 않습니다.

## 문제 해결과 심사 참고

- 세션 도구 부재는 호스트 한계입니다. 수동 인계 절차를 쓰며 플러그인 설치로 해당 도구가 생기지는 않습니다.
- 플러그인 업데이트는 프로젝트 기록을 갱신하지 않습니다. 규칙 변경에는 별도로 승인한 패치가 필요합니다. [업데이트 안내](updating.ko.md)를 참고하세요.
- 프로젝트 파일과 대화 발췌에 개인정보가 포함될 수 있습니다. [데이터 처리 안내](privacy.ko.md)를 참고하세요. 로컬 파일이라고 호스트 처리까지 로컬에서만 이뤄지는 것은 아닙니다.
- 0.2.3 디렉터리는 아이콘·배너 PNG에서 다운로드 실행 패턴을 경고했습니다. 실행 컴포넌트가 선언돼 있지 않은 이미지 파일이며 PNG 구조·CRC 검사를 통과했습니다. 바이너리 내용 탐지로 추정되지만 공식 오탐 판정은 아닙니다. 요청이 오면 실제 파일·버전 근거로 대응합니다.
- 0.2.3 데이터 전용 태그에는 개발 스크립트·저장소 자동화·마켓플레이스 목록이 없으며 개발용 파일은 `main`에 남습니다. 설치·보안 검사와 심사 승인·게시는 구별합니다.
- 일반 문의는 GitHub Issues, 비공개 취약점은 [SECURITY.md](../SECURITY.md)를 이용합니다.
